# Login background

`login-background.jpg` is the exact wallpaper attachment supplied by the maintainer
on 2026-10-15, used for the XIVAuth browser result page. It is bundled as an embedded
server resource and served from a content-hashed same-origin URL. The page makes
no request to Reddit or another image host.

Original reference: https://i.redd.it/8qmfc28eey481.png. The chat attachment is the
source of the committed bytes; it is JPEG, 1920 × 1080. Image rights remain with
their respective creators; the source-code license does not grant image rights.

Replace this asset to change the artwork; its public cache URL changes automatically.
Keep the template's opaque text panel and image-independent dark fallback.
