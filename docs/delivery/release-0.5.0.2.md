# Amor RP 0.5.0.2

- Home → Events uses Noticeboard-style cards with the schedule, location, description, group logo and signature. Opening an event from favorites puts its card first.
- The character menu and member list send trade requests directly. A compact popup shows the countdown and lets you cancel. Recipients can accept or decline from the launcher, and acceptance opens the trade window for both players.
- Recipe Creation has its own tab beside Crafting, with access based on Alchemy and Cooking recipe permissions.

Update the plugin in Dalamud. This release works with server 0.5.0.0.
