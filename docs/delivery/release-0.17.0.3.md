# Amor RP 0.17.0.3

Attack uses the player selected in FFXIV. The attack button checks that
the target is an active season member.

Under Settings → Interface → Actions, set the number of buttons per row, hide
individual buttons, or reorder them with the up and down arrows. Reset button
layout restores the default grid. Rolls go to the Activity Log by default.
Choose a channel under Post rolls to if you also want to post them to chat.

Update the plugin through Dalamud. Server 0.17.0.0 supports this release.

The stable package comes from the [Windows plugin build](https://github.com/Runmih/AmorRP/actions/runs/45498705345).
The same source passed the [server and contracts checks](https://github.com/Runmih/AmorRP/actions/runs/45498705372).
