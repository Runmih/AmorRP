# Amor RP 0.4.0.10 — Required plugin updates

Amor RP verifies the published version before gameplay and checks again every
five minutes. When a newer version is available, Amor RP pauses its gameplay
and offers a shortcut to Dalamud's update list. If the check fails, Amor RP
pauses and retries. Players can also retry from the notice.

The minimum server version remains 0.4.0.3. This installer check starts in
0.4.0.10. Earlier plugins need to update through Dalamud to receive it.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44804854708).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44804854720) passed.
