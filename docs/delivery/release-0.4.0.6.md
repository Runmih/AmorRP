# Amor RP 0.4.0.6 — Home and standalone Inventory

The launcher order is Home, Inventory, Crafting, Writing log, Group Management,
Trade, Season Management and Power. Home opens the season browser with its existing
tabs. The launcher uses a house for Home, a box for Inventory, people for Groups,
scales for Trade and a key for Season Management.

Inventory is a movable, resizable workspace. It keeps its filters, item details
and finance footer. Open it from the launcher or with `/amorrp inventory`. Opening the
FFXIV inventory no longer opens the RP window. Power controls the automatic HUD.

The minimum server version remains 0.4.0.3. Check the launcher order, window toggles
and Inventory resizing in game.
