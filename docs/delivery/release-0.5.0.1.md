# Amor RP 0.5.0.1

- The ♥ Amor RP character submenu offers Trade and, for authorized staff, Billing. The Billing form targets the selected character. Return reopens the game menu.
- Home → Groups now includes group management. The launcher flag and `/amorrp groups` open that same page.
- Members combines the roster and staff controls. Group owners can select a member to edit their permissions or clock them out.

This plugin release works with server 0.5.0.0. It uses the existing billing API and database schema.
