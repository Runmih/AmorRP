# Amor RP 0.11.0.1

- **Shop → Slave** shows the character name and price in columns. A character
  approves their listing once. The Buy button registers the permit immediately
  using the selected group's treasury.
- **Season Management → Weekly limits** presents Alchemy, Cooking, Writing,
  and Gathering and Hunting in one form. The top Save button commits the
  changes together.

Update the home server to 0.11.0.1 before publishing the corresponding plugin.
This release contains no database schema changes. [Home server guide](home-server.md)
