# Amor RP 0.4.0.8 — Panel placement and Activity Log

Interface settings now separate Quick Bar, Automatic HUDs and Favorite Events.
The quick bar and Favorite Events can dock to any edge with optional auto-hide,
or float and be dragged anywhere in the viewport. Favorite Events also has a
background opacity control independent of its text.

Menu title bars have a Settings cog and note icon. The note opens Activity Log,
also available through `/amorrp log`. Recent action results and details stay
available for the current character session. Pending-action recovery lives here
too. The note lights up when an action needs recovery. The launcher handle's
right-click menu is another way to reach Settings or Activity Log.

In game, check dragging and auto-hide on all edges, HUD text legibility with a
transparent background, and Log recovery from another window. The minimum
server version remains 0.4.0.3.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44793606288).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44793606402) passed.
