# Amor RP 0.4.0.16 — Update prompts on demand

Amor RP checks for updates in the background. When an update is required,
the prompt appears when a player tries to open an Amor RP feature.
The quick bar, `/amorrp`, and Dalamud's plugin buttons can open the prompt.

The minimum server version remains 0.4.0.3. In-game acceptance is pending.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44907309967).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44907309922) passed.
