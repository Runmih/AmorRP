# Amor RP 0.4.0.9 — Home tabs and trade grids

Home, Inventory, Crafting and Writing Log share a window. Their quick-launch icons
open the corresponding tabs. Set the navigation edge in Settings → Interface
→ Main window.

Favorite Events shows event titles. Select a title to read its details. Its
settings can hide the header or hide the panel entirely when it is empty.

Move a stack between your Amor RP inventory and offer by dragging it or using
its right-click menu. Choose the quantity when moving more than one item. Each
side has up to 20 item lines on the default server configuration. The trade
still requires both players to accept and confirm.

The minimum server version remains 0.4.0.3. In-game acceptance is pending.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44799644460).
