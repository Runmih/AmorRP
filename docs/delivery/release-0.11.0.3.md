# Amor RP 0.11.0.3

Open the Amor RP activity log with the log icon or `/amorrp log` to inspect
Moodles IPC readiness, application and removal attempts, and the reported
status. Open **Details** on an entry to see the IPC call, its error or the
status readback. Moodles applies effects through an IPC action with no return
value.

This plugin release works with the existing server 0.11.0.2.
