# Amor RP 0.4.0.14 — Player overview and quick-bar badges

Members show character names. Player windows follow the active season, and
administrators browse and activate seasons from Season Management.

The collapsed bar shows a red badge for incoming trades and a blue badge for
unread announcements. Home shows numbered resource bars with one weekly reset.
Noticeboard filtering uses a placeholder inside the search field.

Inventory has a Type column. Home and Inventory show one coin figure that
subtracts outstanding debt from spendable funds.

The minimum server version remains 0.4.0.3. In-game acceptance is pending.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44833197910).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44833198433) passed.
