# Amor RP 0.4.0.11 — Window and group cleanup

Home, Inventory, Crafting and Writing Log display their names in the title bar.
Repeated headings were removed. Each section under Settings → Interface can
collapse.

The trade prompt asks for a simple confirmation. Item details are available
from the offer grid before confirming. Both players still accept and confirm.

Group profiles use a Main tab for the logo, name, description and joining
options. Group owners can set a password there. Favoriting is available in
Home → Groups.

The minimum server version remains 0.4.0.3. In-game acceptance is pending.
