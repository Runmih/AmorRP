# Amor RP 0.4.0.17 — Group filters and simpler item details

Home → Groups has a star beside each group that fills when the favorite is
saved. Search by group name or turn on Favorites only. Treasury Returns was
removed from the group UI.

Inventory shows Item, Type, and Available. Click a row again to close its
details. Use and Discard expand when needed. The Writing Log has a Type column.
Home tabs and View bills use plain text labels.

The minimum server version remains 0.4.0.3. In-game appearance is pending verification.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44910588090).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44910588125) passed.
