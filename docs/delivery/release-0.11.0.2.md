# Amor RP 0.11.0.2

A private permit offer now settles when the recipient clicks **Accept**. Send
the offer through **♥ Amor RP → Enslave**. The recipient can accept or decline
directly from the private offer list. Acceptance pays from the group treasury,
transfers the agreed assets, and registers the permit in one transaction.

Update the server before installing the matching plugin. The migration records
the price authorized at send time. Resend private offers created before the
update. Registered permits remain available. [Home server guide](home-server.md)
