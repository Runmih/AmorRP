# Amor RP 0.17.0.1

- The sword icon on the quick bar toggles the standalone Actions window.
  The `/amorrp actions` command also opens it. Selecting a combat target
  from Members opens Actions with that character selected.
- Home → Character places Stats beside Your resources, with HP at the top
  of the resources panel. On narrow layouts the panels stack.

Update the plugin from Dalamud. Server 0.17.0.0 supports this release.

The stable package comes from the [Windows plugin build](https://github.com/Runmih/AmorRP/actions/runs/45489309752).
The same source passed the [server and contracts checks](https://github.com/Runmih/AmorRP/actions/runs/45489309946).
