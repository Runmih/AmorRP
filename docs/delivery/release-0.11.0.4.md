# Amor RP 0.11.0.4

- Item details start with Consume or Use and Discard. Discard opens a quantity
  dialog. Leave the emote channel blank to use a consumable without sending chat.
- The separate Coins HUD shows your balance after outstanding debt. It uses the
  same docking, display, and opacity settings as Favorite Events.
- Use the refresh icon beside Settings to refresh plugin data. Crafting lists
  show Name, Cost, and Access.
- Home has a Character tab for classes, resources, description, and bills.
  Event cards show European dates and separate Date & Time and Location fields.

Update the home server to 0.11.0.4 before installing this plugin. The server
accepts consumable use without a chat destination. The database schema stays
the same.
