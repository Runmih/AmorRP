# Amor RP 0.17.0.2

Actions is now a standalone HUD with its own controls under Settings → Interface
→ Actions. Show or hide it, drag it to a floating position, or dock it to a
screen edge with optional auto-hide. Adjust its width, opacity, background
opacity, and header visibility.

The Actions button has been removed from the quick bar. Run `/amorrp actions`
to show the HUD directly. Selecting a combat target in Members also shows it
with that character selected.

Update the plugin through Dalamud. Server 0.17.0.0 supports this release.

The stable package comes from the [Windows plugin build](https://github.com/Runmih/AmorRP/actions/runs/45495521759).
The same source passed the [server and contracts checks](https://github.com/Runmih/AmorRP/actions/runs/45495521246).
