# Amor RP 0.4.0.15 — Noticeboard cards and interface icons

Noticeboard entries are cards with a group seal and an automatic handwritten
group signature. Select the seal or signature to open the group. Groups
without a logo use an initial, and signatures can use the regular font when
Caveat lacks a character.

Home uses icons for Members, Groups, Noticeboard, announcements and resources.
Inventory places item icons in the Type column. Search fields have magnifiers
and clear controls, and the collapsed quick-bar handle labels both badges on
hover.

The minimum server version remains 0.4.0.3. In-game appearance is pending verification.

The stable release uses the [Windows package from CI](https://github.com/Runmih/AmorRP/actions/runs/44905371858).
The matching [server workflow](https://github.com/Runmih/AmorRP/actions/runs/44905371863) passed.
